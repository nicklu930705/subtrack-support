App 處理的資料

訂閱名稱、金額、週期、日期、類別、使用日期與付款來源標籤，使用 SwiftData 保存於裝置；預算、外觀及提醒開關使用系統偏好儲存。App 沒有銀行串接、帳號註冊、廣告、分析追蹤或自營後端，不將訂閱紀錄傳給開發者。

Apple 購買及通知

購買、恢復及權限驗證由 Apple StoreKit 處理，Apple 依其政策處理交易與帳號資訊，開發者不接收完整付款資料。App 讀取驗證後的有效權限。提醒在裝置排程，需你的通知授權；拒絕不影響記錄功能。

你主動分享的資料

匯出 CSV 後，由你選擇分享對象；開啟管理網址會前往你指定的外部網站，其資料處理受該網站政策規範。客服郵件只包含你主動提供的內容，由開發者用於處理問題；Gmail 亦依其政策處理郵件。請勿寄送密碼、完整卡號或其他不必要的敏感資訊。

控制、保存與刪除

你可編輯、刪除及匯出紀錄。App 沒有自行提供雲端同步；裝置的系統備份由你的 Apple 設定管理。刪除 App 可能移除本機資料。客服郵件僅在處理支援及必要保存期間保留，可透過客服信箱提出刪除要求。

支援網站

本網站由 GitHub Pages 託管，頁面沒有分析追蹤、登入、表單或廣告程式。依 GitHub 的說明，網站訪客的 IP 位址會為安全目的而記錄及儲存，不論訪客是否登入 GitHub。這些主機紀錄由 GitHub 依其隱私政策處理。
